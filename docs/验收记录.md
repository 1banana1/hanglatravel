## 三、本轮修复的 4 个真实 Bug

| # | 位置 | 症状 | 根因 | 修法 |
|---|---|---|---|---|
| 1 | `src/table.js` `_drop()` | 拖拽高亮正常、松手后**卡片原地不动**，静默失败 | 给 `.tier-row` 设 `pointer-events:none`，而 `.tier-items` 是其**子元素**被一起屏蔽，`elementFromPoint` 落空 → `levelId` 为 undefined 提前 return | 改为只临时隐藏 `.drag-ghost`，与 `_highlightTarget` 保持一致 |
| 2 | `index.html` + `src/table.js` `build()` | 工具栏、统计条、等级筛选、省份下拉**初次渲染就消失** | `build()` 对 `#tablePane` 做 `innerHTML=''`，而这三个静态控件正是它的子元素，被一并删除 | 抽出 `.table-view` 外壳承载静态控件，`#tablePane` 只装 board |
| 3 | `index.html` + `src/map.js` `build()` | 地图图例和缩放按钮不存在（`#legend` 查不到） | 同 #2，`build()` 清空 `#mapPane` 时删掉了 `.map-toolbar` 和 `#legend` | 抽出 `.map-view` 外壳，`#mapPane` 只装 SVG，`position:absolute; inset:0` |
| 4 | `src/app.js` `renderAll()` | 点图例有变灰反馈，但**地图上的点不消失** | `hiddenLevels` 在 `app.js` 维护，从未推给 `MapView` | `renderAll()` 中先调 `mapView.setHiddenLevels(hiddenLevels)` 再渲染 |

Bug #2 和 #3 是同一个反模式（视图组件清空容器时连静态兄弟/子控件一起删），Bug #1 是最隐蔽的一个 —— UI 有高亮反馈、控制台无报错、store 无写入，纯靠插桩打点才定位到。

## 四、附带增强

- **档位折叠**：点档位标签可收起/展开该档，顶栏「全部展开」一键切换

## 五、已知限制

1. 地图为**省级轮廓 + 城市点位**，不是地级市边界填色。这是刻意的体积取舍：地级市边界 GeoJSON 约 5–8 MB，点位方案只要 353 KB 且渲染更快。若需按市辖区填色，需另配数据。
2. 城市经纬度为**市政府驻地近似坐标**，用于点位标记足够，不做精确到景区的定位。
3. 未做 PWA 离线缓存（Service Worker），需要本地 http 服务运行；直接双击 `index.html` 文件会因为 ES module 的 CORS 限制无法加载。
